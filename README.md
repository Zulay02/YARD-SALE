# Yard Sale 🛍️

Pantallas de la tienda **Yard Sale**, maquetadas con HTML y CSS en el **Curso Práctico de Frontend Developer de Platzi**.

👉 Abre `index.html` para ver la lista de todas las pantallas.

## Pantallas

1. Crear una nueva contraseña
2. Correo enviado
3. Iniciar sesión
4. Mi cuenta
5. Editar mi cuenta
6. Página de inicio (productos)
7. Menú de escritorio
8. Menú del celular
9. Mi orden
10. Mis órdenes
11. Barra de navegación
12. Detalle del producto
13. Carrito de compras

## Lo que practiqué

- Variables de CSS (`:root`)
- Flexbox y CSS Grid
- Diseño *mobile first* con `@media`
- Formularios con `label` e `input`
